# Maintainers

The project is maintained by the OSGovt maintainers, who handle reviews,
releases and security response. Reach them at the addresses below.

Day-to-day maintenance (checks, repairs, documentation rehearsals,
findability) runs on an automated pipeline with a human owner; what runs,
when, and what each part may change is in [AUTOMATION.md](AUTOMATION.md).

## Contact

| For | Email |
|---|---|
| General questions | hello@osgovt.com |
| Security vulnerabilities (privately) | security@osgovt.com |
| Accessibility barriers in the software | accessibility@osgovt.com |
| Code of conduct reports (confidential) | conduct@osgovt.com |

Bugs and feature requests go in GitHub issues. Never post passwords, the
contents of `.env`, or residents' personal information anywhere.
