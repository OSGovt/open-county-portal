Open data and API

Everything {{ site.jurisdiction_name }} publishes here is free to use through this website's open API and daily bulk files. No account, key, fee, or contract is required.

What's available

  • Property records index and document page images: /api/v1/instruments
  • Meetings, agendas and minutes: /api/v1/meetings
  • Public notices and required postings: /api/v1/postings
  • Fee schedule: /api/v1/fees
  • Services and offices: /api/v1/services, /api/v1/offices
  • Released public information responses: /api/v1/public-information
  • Everything changed since a date: /api/v1/changes?since=2026-01-01T00:00:00Z

Bulk files

Daily files in CSV and JSON are listed at /api/v1/bulk. Please use them instead of paging through the live API for large downloads.

Machine-readable descriptions

  • API description (OpenAPI): /api/v1/openapi.json
  • Data catalog for Data.gov (DCAT-US 3.0): /data.json
  • Data catalog in DCAT-US 1.1: /data-v1.1.json
