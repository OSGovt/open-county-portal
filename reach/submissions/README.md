# Listing drafts

Each file here is a draft entry for a third-party list or directory
(awesome lists, civic-tech directories, container registries). The weekly
maintenance pass writes the draft and opens a GitHub issue labeled
`reach-submission` pointing at it. Nothing is sent until a maintainer says
yes on that issue; then the maintainer (or a session they start) submits it
and the file gains a `Submitted:` line with the date and link.

Every claim in a draft must trace to a file in this repository.
